# Weather Dashboard

## Project Overview

Weather Dashboard is a web application that allows users to search for cities and view current weather conditions, forecasts, and temperature charts.

## Planned Features

- Search weather by city
- Display current weather conditions
- View hourly and daily forecasts
- Display temperature charts
- Save favorite cities
- User authentication

## Planned Technologies

- HTML5
- CSS3
- JavaScript
- Python
- FastAPI
- PostgreSQL
- Git and GitHub

## Project Structure

The frontend and backend will be organized separately as the project develops.

## Project Goal

Build a weather dashboard while learning web architecture, frontend development, backend development, database integration, testing, and deployment.
